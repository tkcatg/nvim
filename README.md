# Install
置き場所は[公式](https://neovim.io/doc/user/vim_diff.html#nvim-config)にならう

## macOS/FreeBSD/Linux
```sh
$ mkdir -p ~/.config
$ cd .config
$ git clone git@github.com:tkcatg/nvim.git
```

## Windows
```cmd
$ cd %LOCALAPPDATA%
$ git clone git@github.com:tkcatg/nvim.git
```

### vscode環境
`%APPDATA%\Code\User\`に`settings.json`と`keybindings.json`を配置する.
```cmd
$ cd vscode
$ setting.bat install
```
